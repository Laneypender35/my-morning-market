GitHub Pages setup
1Create a new repo — e.g. my-morning-market
2Upload index.html to the root of the main branch
3Go to Settings → Pages → Source → Deploy from branch → main / root
4Your site will be live at https://yourusername.github.io/my-morning-market
⚠When self-hosting, add your Anthropic API key to the aiSearch() fetch headers — and use a backend proxy to keep it out of the public repo.
